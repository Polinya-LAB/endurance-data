# endurance-data

Datos de la app **Seguimiento piscina durabilidad**:
https://polinya-lab.github.io/management-tools/seguimiento-piscina-durabilidad/

- `piscina.json`: bombas, HotBox, observaciones y ajustes (incluido el precio del kWh por mes).
- La app guarda cada cambio como un commit: el historial del archivo muestra quién cambió qué y cuándo.
- Para modificar desde la app, tu cuenta de GitHub necesita el rol **Write** en este repositorio.
- No edites el archivo a mano mientras alguien usa la app: puede pisar sus cambios.

El código de la app está en [Polinya-LAB/management-tools](https://github.com/Polinya-LAB/management-tools).
El historial anterior al 16/10/2026 está en `management-tools`, carpeta `seguimiento-piscina-durabilidad/data/`.
